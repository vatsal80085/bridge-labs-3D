- Practiced 1D, 2D, and multi-dimensional arrays

**Strings:**  
- Used `String`, `StringBuilder`, `StringBuffer`, `StringTokenizer`

- Passed strings as parameters  
- Reviewed ASCII character codes  

**Methods:**  
- Wrote own methods (user-defined)  
- Explored static & library methods  
- Played with `Math` class methods (`Math.random()`)  

**Takeaway:** Strings + methods made my code more reusable, dynamic, and powerful.  

---

### Session 7 – Object-Oriented Programming (OOP)
- Understood the 4 pillars of OOP:
  - **Encapsulation** → bundling data & methods inside classes  
  - **Abstraction** → hiding implementation details, focusing on behavior  
  - **Inheritance** → reusing parent class properties in child classes  
  - **Polymorphism** → same method behaving differently (overloading/overriding)  
- Practiced creating classes & objects  
- Learned about constructors (default, parameterized)  
- Explored `this` & `super` keywords  
- Implemented method overloading & overriding  
- Got an intro to `interfaces` and `abstract classes`  

**Takeaway:** OOP helps me structure code like real-world entities—more modular, reusable, and scalable.
